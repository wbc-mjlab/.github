# wbc-mjlab/.github

Organization profile and shared GitHub config for [wbc-mjlab](https://github.com/wbc-mjlab).

| Path | Role |
|------|------|
| **[profile/README.md](profile/README.md)** | Org profile — rendered at https://github.com/wbc-mjlab |
| **[site/](site/)** | Academic one-pager (Eleventy) — GitHub Pages at https://wbc-mjlab.github.io/.github/ |

## Project page

```bash
cd site
npm install
npm start    # local preview
npm run build
```

Enable **Settings → Pages → Source = GitHub Actions** once, then push to `main` (or run **Deploy Pages**).
